# بوت حقوق قنوات تلغرام — Termux وPM2

بوت بايثون يعمل بالكامل داخل Termux عندك باستخدام Long Polling؛ لا يحتاج دوميناً، استضافة خارجية، API_ID أو API_HASH. يحتاج إنترنت وتوكن بوت من @BotFather. الحقوق هنا **نص أسفل المنشور أو وصف الوسائط**، وليست علامة مائية داخل الصورة أو الفيديو.

## ما الذي يعمل؟

- إضافة حقوق مخصّصة للمنشورات الجديدة: النصوص والصور والفيديو والملفات والصوت والرسائل الصوتية وGIF.
- لوحة عربية بأزرار لكل قناة لتفعيل وتعطيل الحقوق، زر اسم القناة ورابطها، والتصويت بلايك ودس لايك.
- خيار حذف الروابط والمعرّفات التي يتعرف عليها تلغرام من نص المنشور أو وصفه قبل إضافة حقوقك. **هذا الخيار يحذف كل الروابط والمعرّفات المكتشفة، لا يميّز حقوق الآخرين من الروابط المفيدة.** الرابط المخفي يحذف معه النص المرتبط به. الخيار معطّل افتراضياً.
- الحفاظ على تنسيق النص، ودعم الإيموجي بإزاحات UTF-16 الصحيحة.
- إدارة عدة قنوات من حساب مالك واحد، مع حفظ إعدادات كل قناة والتصويت في SQLite.
- يملك كل مستخدم صوتاً واحداً لكل منشور؛ الضغط على نفس الخيار يلغي صوته، والضغط على الآخر ينقله.
- لا يحذف البوت منشورات ولا يعيد نشرها. يعالج المنشورات الجديدة في مكانها.

هذه نسخة تركّز على الحقوق، وليست استنساخاً لكل أزرار الصورة: لا تشمل المسابقات أو المشاركة أو الرد على التعليقات أو إزالة علامة «مُعاد توجيهها». لا تزيل علامات مائية مدمجة في الوسائط.

## 1. تثبيت المتطلبات في Termux

استخدم إصدار Termux حديثاً ومدعوماً. نفّذ:

```bash
pkg update && pkg upgrade -y
pkg install python nodejs-lts unzip nano -y
npm install -g pm2
termux-setup-storage
```

امنح إذن الوصول للملفات، وحمّل ملف `telegram-rights-bot.zip` في مجلد التنزيلات. أبقِ المشروع داخل مجلد Termux الرئيسي، لا داخل التخزين المشترك:

```bash
cd "$HOME"
unzip -q "$HOME/storage/downloads/telegram-rights-bot.zip"
cd "$HOME/telegram-rights-bot"
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
nano .env
chmod 600 .env
```

إذا كان الملف في مكان آخر، عدّل مسار ملف ZIP بالأمر أعلاه. لا تحتاج ترقية pip الخاص بالنظام.

## 2. القيم الضرورية

عدّل السطرين داخل `.env` فقط:

```dotenv
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
OWNER_ID=YOUR_NUMERIC_TELEGRAM_USER_ID_HERE
```

`BOT_TOKEN`: توكن البوت من @BotFather. `OWNER_ID`: رقم حسابك الشخصي على تلغرام، وليس اسم المستخدم أو رقم القناة. يمكنك معرفته ببوت موثوق يعرض معرّف الحساب. لا ترسل ملف `.env` لأحد.

معرّف القناة لا يحتاج وضعه في الكود؛ تسجّل القنوات من تلغرام بعد التشغيل.

## 3. التشغيل مع PM2

```bash
cd "$HOME/telegram-rights-bot"
termux-wake-lock
pm2 start ecosystem.config.js
pm2 save
pm2 status
pm2 logs telegram-rights --lines 40
```

اخرج من عرض السجل بـ Ctrl+C؛ هذا لا يوقف البوت. أوامر الإدارة:

```bash
pm2 restart telegram-rights
pm2 stop telegram-rights
pm2 delete telegram-rights
```

شغّل نسخة واحدة فقط لكل توكن. لا تستخدم وضع cluster، ولا تشغّل `python bot.py` بينما نسخة PM2 تعمل؛ تشغيل نسختين يؤدي إلى تعارض استقبال التحديثات. بعد تعديل `.env` يكفي `pm2 restart telegram-rights`، ما لم تكن قد وضعت نفس القيم كمتغيرات بيئة خارجية لها أولوية على الملف.

## 4. ربط القناة وضبط الحقوق

1. افتح البوت وأرسل `/start` من حسابك المحدّد في `OWNER_ID`.
2. أضف البوت **مشرفاً** بقناتك وامنحه **تعديل الرسائل**. لا يحتاج صلاحية حذف الرسائل أو نشرها لهذه النسخة. يجب أن يكون حسابك أنت أيضاً مالكاً أو مشرفاً في القناة.
3. أرسل للبوت في الخاص:

```text
/add @channel_username
```

للقناة الخاصة استخدم معرّفها الرقمي الصحيح، مثال شكلي:

```text
/add -1001234567890
```

هذا مثال وليس معرّف قناتك. يمكنك العثور على المعرّف في رابط منشور خاص مثل `https://t.me/c/1234567890/17`: رقم القناة بهذا المثال هو `-1001234567890`.

4. أرسل `/channels`، اختر القناة ثم اضغط **تعيين نص الحقوق** وأرسل النص المطلوب. مثل:

```text
جميع الحقوق محفوظة لقناة مثال ©
@my_channel
```

5. فعّل ما تريد من الأزرار وانشر منشوراً تجريبياً. لزر القناة الخاصة، عيّن رابط دعوة صالحاً أولاً. `/cancel` يلغي إدخال الحقوق أو الرابط، و`/id` يعرض معرّف حسابك.

الأزرار الإدارية تعمل للمالك فقط وفي الخاص. زر الإزالة يزيل القناة من إعدادات البوت بعد تأكيد ثانٍ، دون المساس بمنشوراتها. إعدادات الأزرار الجديدة لا تعيد كتابة أزرار المنشورات السابقة؛ تصويتها السابق يبقى متاحاً.

## 5. بقاؤه يعمل على الهاتف

عطّل تحسين البطارية لتطبيق Termux، واسمح له بالعمل بالخلفية. `termux-wake-lock` يساعد لكنه لا يمنع أندرويد من قتل التطبيق ولا يعوّض انقطاع الإنترنت أو إطفاء الهاتف.

PM2 يعيد تشغيل البوت إذا توقفت عملية بايثون بينما Termux نفسه ما زال يعمل. بعد إعادة فتح Termux:

```bash
termux-wake-lock
pm2 resurrect
```

التشغيل بعد إعادة تشغيل الهاتف ليس تلقائياً بأوامر PM2 وحدها. إن أردته، ثبّت Termux:Boot من نفس مصدر تثبيت Termux وافتحه مرة واحدة، ثم أنشئ داخل Termux:

```bash
mkdir -p "$HOME/.termux/boot"
printf '%s\n' '#!/data/data/com.termux/files/usr/bin/sh' 'termux-wake-lock' 'sleep 10' '/data/data/com.termux/files/usr/bin/pm2 resurrect' > "$HOME/.termux/boot/start-rights-bot"
chmod +x "$HOME/.termux/boot/start-rights-bot"
```

شغّل `pm2 save` بعد تغيير قائمة عملياتك. لا تستخدم `pm2 startup` المعتمد على خدمات Linux مثل systemd داخل Termux المعتاد.

## حدود مهمة

- يعدّل المنشورات الجديدة التي تصل أثناء عمل البوت أو ضمن التحديثات المعلّقة التي ما زالت تلغرام تحتفظ بها؛ لا يسحب سجل القناة القديم. لا يعتمد على تحديثات التعديل لتجنّب حلقات التعديل؛ إذا عدّلت المنشور يدوياً لاحقاً لن يعيد تركيب الحقوق تلقائياً.
- حدود Telegram المعتادة: 4096 للنص و1024 لوصف الوسائط. يفحص الكود الطول بوحدات UTF-16 بشكل محافظ. إذا لم تتسع الحقوق، يبقي النص الأصلي كاملاً وينبّه المالك؛ لا يقصّ المنشور. عندها يتجاوز تنظيف النص أيضاً، ويمكنه إضافة الأزرار إن كانت مفعّلة.
- الألبوم يُجمع لمدة قصيرة (1.5 ثانية) وتوضع الحقوق والأزرار على عنصر واحد: العنصر ذو الوصف إن وصل خلال المهلة، وإلا أول عنصر. لا يعيد نشر الألبوم أو يكرر الحقوق على كل صورة. مع وصول متأخر جداً قد تكون الحقوق على عنصر مختلف عن العنصر ذي الوصف.
- الاستطلاعات والملصقات وملاحظات الفيديو الدائرية والمحتوى المدفوع والرسائل الخدمية ليست ضمن المحتوى الذي تعالجه هذه النسخة.
- تغيير اسم القناة يتطلب تسجيلها مجدداً بـ `/add` لتحديث الاسم المحفوظ. عند تغيير معرّفها العام حدّث الرابط من اللوحة.
- يجب ألا يستخدم التوكنَ خادم آخر أو Webhook فعّال. إذا سبق أن ربطته بخدمة Webhook، افصلها أولاً قبل تشغيل هذه النسخة.
- عند فشل تعديل بسبب صلاحية أو خطأ اتصال، قد يبقى المنشور المعني بدون حقوق. السجل والرسالة الخاصة ينبّهانك؛ لا يدّعي الكود ضمان تسليم كل تعديل عند أي انقطاع.
- خيارات إزالة الروابط لا تثبت ملكية المحتوى. استخدمها للمحتوى الذي تملك حق نشره.

## الاختبار والنسخ الاحتياطي

```bash
cd "$HOME/telegram-rights-bot"
.venv/bin/python -m unittest -v test_bot.py
```

الاختبارات محلية ولا تستخدم التوكن ولا تتصل بتلغرام. اختبر أيضاً منشوراً فعلياً وصورة وألبوماً بعد التركيب للتحقق من صلاحيات قناتك.

قاعدة البيانات `bot.sqlite3` تنشأ عند التشغيل. لنسخة احتياطية بسيطة ومتسقة، أوقف البوت مؤقتاً وانسخ القاعدة ثم شغّله:

```bash
pm2 stop telegram-rights
cp bot.sqlite3 bot.backup.sqlite3
pm2 start telegram-rights
```

احتفظ أيضاً بـ `.env` في مكان آمن. ملفات القاعدة تحتفظ بمعرّفات القنوات والمستخدمين المصوّتين؛ لا تنشرها. السجلات وبيانات التصويت والمعالجة تنمو مع الاستخدام، فراقب مساحة الجهاز. الأزرار القديمة تعتمد على بقاء قاعدة البيانات.
